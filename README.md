# 肉贸智达 · 云端自动更新（汇率 + 活畜价格）

这套东西做三件事：
1. 每天傍晚自动去取**汇率**（美元、澳元、新西兰元等）和**活畜价格**（巴西 CEPEA、澳洲 MLA 指标），
2. 存成一个文件 `data/latest.json`，
3. 肉贸智达打开时自动读取，汇率表和活畜价格表就自动更新了。

不用花钱，用的是 GitHub 的免费服务。**只需要在电脑上操作一次，大约 15 分钟。**

---

## 先说清楚三件事

- **Claude 里的那个页面不能联网**，所以它读不到这个文件，只能"手动导入文件"。想要"打开就自动更新"，要把肉贸智达放到你自己的网址上（下面第 5 步，本包里的 `index.html` 就是已经带好自动读取功能的程序）。
- **取数据的程序我在这里没法连真实网站测试**。解析逻辑我用模拟网页测过，但真实网站可能有反爬或改版，**第一次运行请看日志**（第 6 步），有哪个来源失败，把日志发给我，我来改。
- 汇率优先取**中国银行现汇卖出价**（和你现在用的一致）。取不到时，用市场中间价（open.er-api.com）补，备注里会写明来源，数值会和中行价差 0.3%–0.5%。
- 目前已接入：中行汇率、巴西 CEPEA、澳洲 MLA 指标。**中国、乌拉圭、阿根廷、新西兰还没接入**（这些网站结构各不相同，需要先看到真实页面再写），暂时仍由我在你说"更新活畜价格"时帮你补。

## 操作步骤

### 1. 注册 GitHub
打开 https://github.com ，用邮箱注册一个账号（免费）。

### 2. 新建仓库
- 登录后点右上角 **＋ → New repository**
- Repository name 填：`rmzd`
- 选 **Public**（免费账号使用网页托管需要公开；里面只有公开的汇率和价格数据，以及程序本身，**不含你的任何业务数据**，你的数据只存在你自己的浏览器里）
- 勾选 **Add a README file**，点 **Create repository**

### 3. 上传文件
- 先把本压缩包**解压**到电脑
- 在仓库页面点 **Add file → Upload files**
- 把解压出来的**所有内容**拖进去：`index.html`、`data` 文件夹、`scripts` 文件夹、`tests` 文件夹，以及 **`.github` 文件夹**（注意：它是隐藏文件夹，Windows 需要在"查看"里勾选"隐藏的项目"，Mac 按 Command+Shift+. 显示）
- 拉到页面下方，点 **Commit changes**

> 如果隐藏文件夹上传不上去：在仓库页面点 Add file → Create new file，文件名输入 `.github/workflows/daily.yml`（输入斜杠会自动建文件夹），把本包里同名文件的内容复制粘贴进去，再点 Commit。

### 4. 打开自动运行
- 点仓库上方的 **Actions**，如果出现提示，点 **I understand my workflows, go ahead and enable them**
- 点左边 **每日取汇率和活畜价格** → 右边 **Run workflow → Run workflow**，先手动跑一次
- 等 1–2 分钟，出现绿色对勾就成功了。之后每天北京时间 18:30 自动运行。

### 5. 打开网页托管（让程序有自己的网址）
- 点仓库 **Settings → Pages**
- Source 选 **Deploy from a branch**；Branch 选 **main**，文件夹选 **/(root)**，点 **Save**
- 等一两分钟，页面上会显示网址：`https://你的用户名.github.io/rmzd/`
- 用手机或电脑打开这个网址，就是肉贸智达。可以"添加到主屏幕"。

### 6. 检查有没有成功
- 打开 `https://你的用户名.github.io/rmzd/data/latest.json`，能看到数据，`updated` 是最近的时间，说明云端在工作。
- 想看每个来源有没有取到：仓库 **Actions** → 点最近一次运行 → 点 **fetch** → 展开 **取数据**，里面每个来源一行，例如：
  - `中行牌价：取到 USD,AUD,NZD ...` ✔
  - `CEPEA 失败：...` ✘（把这行发给我）

### 7. 把现有数据搬过去
新网址是一个新的"家"，浏览器里的数据不会自动过去：
- 在**现在用的肉贸智达**里：备份恢复 → 一键备份（建议填一个备份加密密码）
- 在**新网址的肉贸智达**里：备份恢复 → 选择备份文件恢复
- 之后新网址每次打开，会自动读取云端数据，汇率页签里"云端数据"一栏会显示上次同步时间。你手动改过的数据不会被覆盖。
